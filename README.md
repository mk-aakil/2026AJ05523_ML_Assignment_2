# Bean Class Benchmarking

Machine Learning Assignment 2 - 2026AJ05523

## Problem Statement

Develop and compare five supervised machine learning classifiers to predict dry bean varieties using geometric features.

## Dataset

- Source: UCI Dry Bean Dataset
- Observations: 13,611
- Input features: 16
- Target classes: 7
- Task: Multiclass classification

## Planned Models

- Logistic Regression
- Decision Tree
- K-Nearest Neighbors
- Gaussian Naive Bayes
- Support Vector Machine

## Planned Evaluation

Accuracy, macro Precision, macro Recall, macro F1, multiclass ROC-AUC and MCC.

## Streamlit Application

The application will provide an interactive Model Benchmark Arena featuring:

- Default held-out test dataset
- All Models comparison view
- Individual model selection
- Test CSV upload
- Classification metrics and confusion matrices
- Downloadable predictions
